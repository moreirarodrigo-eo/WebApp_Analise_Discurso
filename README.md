# Laboratório de Análise de Discurso & PLN — V2

Aplicação estática HTML/JavaScript pronta para Netlify.

Funcionalidades: visão geral do corpus, frequência, wordcloud, unigramas/bigramas/trigramas, KWIC configurável, coocorrência, sentimento lexical, codificação temática assistida, comparação entre dois textos, importação TXT/CSV e exportação CSV/HTML.

Publique a pasta no Netlify via drag-and-drop ou `netlify deploy --prod`.

Nota: o modo Bardin usa heurística morfológica porque a aplicação estática não executa UDPipe/R. A análise de sentimento é lexical e exploratória.
